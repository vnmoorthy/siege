02 / The learning loop

Every successful attack
becomes evidence for a fix.

A concrete failure. An exact label.

A $100 store credit exceeds the demo store’s $20 limit. If the gate allows it and the tool executes, that is a breach. The oracle reads the facts; its verdict is never shown to the gate.

The gate controls execution. The oracle measures it.
Illustrative trace / credit abuse
proposed_action  grant_store_credit
amount           $100  // policy limit: $20
gate             allow
oracle           forbidden
executed         true
result           BREACH → defender evidence

Security has to preserve usefulness.

A candidate must improve the evaluated catch rate and keep benign allow at or above the configured floor. Blocking everything fails this test; a rejected candidate leaves the current gate active.
